# 一点点 · 学习小花园

在线使用：https://estebanfranciscowei.github.io/study-garden/

从五分钟开始，完成学习收获金币，兑换自己的小奖励。

## 新增功能

- 常用目标支持修改、增加、删除和排序：点击任务输入框下面的“编辑”，每行一个目标。
- 顶部“界面模式”可选浅色、深色或跟随系统，外观偏好按设备保存。
- 邮箱和密码注册、登录。同一账号在电脑和手机上共享学习记录、金币、常用目标及自定义奖励。
- 支持邮箱确认和密码重置。账号密码由 Supabase Auth 处理，页面不会将密码保存到本机记录或数据库记录中。
- 联网时自动上传本机变化并定期读取云端，也可以在账号面板点击“立即同步”。
- 断网后继续在本机记录，恢复连接后按记录编号合并；重复同步不会重复计算同一条学习或兑换记录。

## 第一次使用账号同步

1. 点击顶部云朵图标“登录同步”，注册邮箱账号。
2. 如需邮箱确认，确认后回到网站登录。
3. 如果已经在这个浏览器里使用过旧版，登录后点击“合并本机未登录时的记录”。合并前会提示确认，未登录记录也会继续保留。
4. 在另一台设备登录同一个账号。保持联网，查看底部同步状态；也可点击“立即同步”。

每台设备独立计时，计时、声音与外观偏好不会互相覆盖。账号之间的数据相互隔离；退出后回到这个浏览器的未登录记录。

已同步的历史记录会合并保留。登录时导入备份会合并记录，不会清空云端历史。未登录时仍可用备份文件替换本机记录。请定期保留备份。

## 部署方式

前端由 GitHub Pages 从 `main` 分支根目录发布，无需构建。账号认证和用户数据由单独的 Supabase 项目提供。

- `index.html`：界面、计时、主题、账号与同步逻辑。
- `cloud-config.json`：Supabase 项目 URL 和可公开的 publishable key，不包含管理密钥。
- `supabase/migrations/20261015_study_garden_accounts.sql`：数据库结构、账号行权限与原子合并函数。
- `.nojekyll`：直接提供静态文件。

换用自己的 Supabase 项目时，在 SQL 编辑器执行迁移，在 Auth URL Configuration 中配置网站地址及允许的跳转地址，然后更新 `cloud-config.json` 中的 URL 和 publishable key。不要使用 secret key 或 service_role key。

直接从本地 HTML 文件打开时，仍可使用本机学习功能；账号服务从已发布的网址使用。
