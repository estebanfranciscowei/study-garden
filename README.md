# 一点点 · 学习小花园

从五分钟开始，完成学习收获金币，兑换自己的小奖励，让花园一点点长大。

[在线使用](https://estebanfranciscowei.github.io/study-garden/) · [版本记录](CHANGELOG.md) · [反馈问题](https://github.com/estebanfranciscowei/study-garden/issues)

**当前版本：2026.10.18**。原生 HTML、CSS 和 JavaScript，无前端构建步骤；不登录也可以使用，登录后通过 Supabase 同步账号记录。

## 功能

| 模块 | 支持内容 |
| --- | --- |
| 专注计时 | 5 / 10 / 25 分钟快捷选择，1–120 分钟自定义，暂停、继续、重新开始，关闭页面后恢复倒计时 |
| 金币与奖励 | 每完成 1 分钟获得 2 枚金币；所有奖励均可编辑名称、时长、价格和图标，包括四项默认奖励 |
| 今日任务 | 分类、计划日期、拆成最多 12 小步、拖动和箭头排序、勾选完成；点击任务开始计时 |
| 学习复盘 | 完成后选填收获和下一步，自动保存；从历史记录编辑、搜索，一键填入下次目标 |
| 学习记录 | 今天、近 7 天、本月、全部或自选日期；按类型、分类、关键词筛选，每页 20 条；点击趋势柱查看明细 |
| 长期花园 | 按累计学习时间成长；5 种植物、3 种摆放方式、4 个季节，继续积累可扩展花圃 |
| 声音 | 3 种约 4 秒的单次完成提示音、独立音量、试听和停止；轻雨、溪流、白噪音背景音及独立音量 |
| 界面 | 浅色、炭灰深色、跟随系统；沉浸视图；适配桌面和手机屏幕 |
| 数据 | 本机保存、JSON 备份导入导出、邮箱账号、自动同步、离线记录后恢复同步 |

背景音默认关闭，只在专注运行时播放，暂停、休息或结束时停止。提示音默认关闭。所有音效均由浏览器生成，无需下载外部音频。花园按累计时间解锁，不消耗金币，也不会因几天没来而枯萎。

### 结束提醒

计时结束后，弹窗、醒目的计时卡片和“已结束多久”会保留到你点击确认，计时器不会立即恢复成准备状态。声音只播放一次，约 4 秒，可以提前停止；按 Esc 只停止声音，点击确认按钮才关闭完成提示。刷新页面仍可看到尚未确认的结束状态，提醒时长不额外计入学习记录或发放金币。

在“提示音设置”中可以主动开启系统通知。浏览器允许后，结束时会发送通知，点击可尝试返回页面。普通网页无法强制盖过其他软件，也无法保证在手机后台、锁屏或网页关闭时准时响铃、亮屏；系统通知的显示方式由设备和浏览器决定。

### 快捷键

| 按键 | 操作 |
| --- | --- |
| `Space` | 开始 / 暂停 / 继续 |
| `F` | 切换沉浸视图 |
| `Esc` | 退出沉浸视图；弹窗打开时优先关闭弹窗 |

在输入框、可编辑区域或弹窗中，计时快捷键不会触发。

## 快速开始

### 直接使用

打开[在线网站](https://estebanfranciscowei.github.io/study-garden/)，写下一件小事，选择时长并开始。完成计时后获得金币，可以兑换奖励并开始休息。

四个默认奖励右上角均有编辑入口，支持恢复初始设置；还可以添加自定义奖励。编辑只影响以后兑换，已经产生的兑换记录和正在进行的休息保持原样。

### 本地运行

下载或克隆整个仓库后，可以直接打开 `index.html` 使用本机功能。请保留同目录下的 CSS 和 JavaScript 文件。

如需本地使用账号服务，建议通过 HTTP 服务打开。例如已安装 Python 时：

```sh
git clone https://github.com/estebanfranciscowei/study-garden.git
cd study-garden
python -m http.server 8000
```

访问 `http://localhost:8000`。账号服务需要联网，并在 Supabase 中配置相应的跳转地址。以 `file://` 打开时不加载账号服务。

## 账号与数据

1. 点击顶部“登录同步”，使用邮箱和密码注册、登录。
2. 如果启用了邮箱确认，确认后回到网站登录。
3. 如需带入原来的未登录记录，在账号面板选择“合并本机未登录时的记录”。原来的未登录数据仍保留。
4. 在另一台设备登录同一账号。联网时自动同步，也可点击“立即同步”。

| 数据 | 保存与同步方式 |
| --- | --- |
| 学习记录、兑换记录、金币 | 本机保存；登录后同步，同一编号的记录去重，金币按学习和兑换记录计算 |
| 任务、复盘、花园布置 | 本机保存；登录后同步，任务和复盘按条合并 |
| 常用目标、当前目标、预选时长、奖励设置 | 本机保存；登录后按字段更新时间合并 |
| 正在进行的计时 | 本机保存，各设备独立计时 |
| 提示音设置 | 本机保存，不上传云端；账号与未登录记录分别保留 |
| 主题、背景音设置 | 按浏览器保存，不上传云端 |

同一浏览器的不同账号和未登录记录分开保存。退出账号后回到未登录记录。账号切换后，原账号尚未提交的编辑或确认操作会被拦截，避免作用于新账号。

### 合并和备份规则

- 学习与兑换历史按记录编号合并保留。登录时导入备份会合并记录；未登录时导入会替换本机数据，并要求确认。
- 任务和复盘按 `updatedAt` 合并，同时间戳以云端数据为准。删除任务保留删除标记，防止离线设备恢复后让任务重新出现。
- 旧备份无需转换；没有图标的旧自定义奖励仍显示礼物图标。默认奖励修改以稳定编号保存在原有的奖励同步字段中。
- 任务最多保存 1000 项（包含删除标记），奖励个性设置最多 50 项。学习和兑换记录各有 100000 条的校验上限，导入文件上限为 5 MB。
- 数据位于当前浏览器的本地存储中。更换浏览器、清除网站数据或使用隐私模式会影响本机数据；建议定期导出备份。
- 关闭页面后不会在后台播放提示音；再次打开时按保存的截止时间恢复并结算。浏览器可能要求先点击页面才能播放声音。

登录凭据由 Supabase Auth 提供；页面不将密码写入本机学习记录或数据库记录。账号登录凭据保存在当前浏览器，用于续期和同步。

## 部署

### GitHub Pages

当前站点由 `main` 分支根目录发布。仓库设置中选择 **Pages → Deploy from a branch → main → /(root)**，保存后等待部署完成。

前端不需要运行 npm 或打包。发布时必须一并包含：

```text
index.html
appearance.css
study-tools.css
study-tools.js
completion-alerts.js
cloud-config.json
.nojekyll
```

`tests/`、`package.json` 和锁文件仅用于开发检查，不参与页面运行。

### 配置自己的 Supabase

1. 创建 Supabase 项目，在 SQL 编辑器中依次执行：
   - `supabase/migrations/20261015_study_garden_accounts.sql`
   - `supabase/migrations/20261017180753_study_tools_sync.sql`
2. 在 Auth 中启用邮箱登录，按需要设置邮箱确认。
3. 在 **Auth → URL Configuration** 配置正式网站地址及允许的本地、正式跳转地址，用于邮箱确认和密码重置。
4. 更新 `cloud-config.json`：

```json
{
  "url": "https://YOUR_PROJECT.supabase.co",
  "publishableKey": "sb_publishable_YOUR_PUBLIC_KEY"
}
```

该文件会由浏览器公开读取，应使用项目的 publishable key，不能放入 secret key 或 `service_role` 密钥。

数据库通过行级权限限制账号只能读取自己的记录；写入由校验登录身份的合并函数完成。新页面使用 `study_garden_merge_v2`；原 `study_garden_merge` 保留，兼容旧页面。本仓库在线站点对应的两次迁移均已应用。

## 开发与检查

需要 Node.js 20 或更高版本。网页运行不依赖 Node.js。

```sh
npm ci
npx playwright install chromium
npm test
```

仅检查 JavaScript 语法、HTML 编号、资源文件和公开配置：

```sh
npm run check
```

也可以使用已安装的 Edge。在 PowerShell 中：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm test
```

测试使用独立浏览器环境和合成数据，不登录真实账号，也不修改真实学习记录。截图和备份样本输出至 `output/playwright/`，已排除出版本控制。

回归覆盖奖励编辑、记录分页和日期边界、主题、声音与快捷键、任务和复盘、花园、备份兼容、320 / 390 像素布局，以及账号切换、延迟失败响应、多标签页结算、无变化同步时的焦点保留。云端请求在浏览器回归中使用模拟响应；数据库权限另行检查。真实邮箱收发和手机实机体验仍需人工验证。
